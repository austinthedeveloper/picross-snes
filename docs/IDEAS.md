# Ideas

Unplanned; not to be built by accident.

- **Sound** (planned for 0.2): SNESMOD effects for fill, mark, erase, line
  done, mistake, solve, menu moves; synthesized in Python like Pickleball
  '94's `tools/assetgen`.
- **Live thumbnail** in the HUD corner: the board so far, one pixel a cell
  (a 20x20 is 3x3 tiles), updated per changed cell.
- **16-pixel cells** for 5x5 and 10x10 boards (2x2 tiles a cell).
- **Murals**: the web game's tiled pictures (16 of them), each tile a
  puzzle; the mural fills in as you solve its tiles.
- **A vertical 4-pixel scroll** on 20x20 boards, so row 0 isn't needed.
- **Clue-by-clue dimming**: dim each finished run's number, not only whole
  lines (the web game's `clues.ts`).
- **Puzzle select by picture**: show solved thumbnails in the list.
- **A fight or two**: a single boss with fog and scramble as a bonus
  collection, once version 1 is done.
- **Name reveal sparkle**: the solved picture animates (palette cycle).
